# Project state

- **Phase and milestone** — Phase 2. The standalone preview and material error report are recorded, and P2-001 verified placement and native 3MF persistence. The P2-002 offline comparison, P2-003 direct rectangle fixture and P2-004 native persistence tests passed. The generic path audit identified clearance and footprint concerns.
- **Git baseline** — The project history continues from FullSpectrum `v0.9.14` at `cc152a84dde21edde575b6cd2266168acc5f401c`. The pre-publication comparison used the complete source tree from GitHub's `main`. All baseline paths were present locally, with project-specific changes layered on top.
- **Milestone workflow** — After major changes, agents validate, stage, commit, and push the task to a `codex/` branch for review. See [agent instructions](../AGENTS.md#stage-and-push-major-changes).
- **Windows Release baseline** — The corrected x64 dependency build, application build and all five existing test targets succeeded. CTest ran 385 cases, with 377 passes and eight failures. All eight reproduced, including one placeholder-parser crash. After adding the placement and routing cases, the suite passed 380 of 388 with the same eight failures. The P2-003 app rebuild and regression run reproduced that result. P2-004 and P2-005 each added a passing case for 382 of 390, with the same eight failures. See [run evidence](test-results/P0-002-windows.md#completed-windows-release-baseline).
- **Standalone verification** — The planar field samples B fraction in millimeters and handles a sharp split at width zero. The two fixture bodies retain distinct bounds in a shared frame. The 4×4×4 grid assigns deterministic labels to occupied cells. All nine standalone tests passed. The field and assignment stage are standalone.
- **P2-006 material split** — Prepare's Cut tool has an opt-in plane split with two filament selectors. Applying the split keeps the solid parts in one object with a sharp boundary. The Windows desktop check verified numeric and drag adjustment, per-part assignments and two-filament offline slicing. The offset and tilted cut regression passed, and full CTest passed 383 of 391 with the same eight Windows baseline failures.
- **Constraints and open evidence** — Preserve default slicing and require explicit interface selection. Nested STEP placement and native 3MF persistence passed for the audited fixture. Third-party material mapping and H2D hardware compatibility remain unverified. The [H2D offline overlay](test-results/P2-005-h2d-profile.md) loads and slices within the shared dual-nozzle envelope.
- **P2-007 gradual transition** — The Cut tool stores an adjustable material band on one solid. The Windows Release offline fixtures passed for horizontal and tilted planes, native 3MF round-trip, and restoration of ordinary slicing after removal. Full CTest passed 384 of 392 with the same eight baseline failures. See the [implementation plan and math](TASKS.md#p2-007-implementation-plan).
- **P2-008 through P2-010** — Raw offline exports verified the T0/T1 assignments and extrusion coordinates for horizontal, tilted, diagonal XY and shared-face STEP fixtures. The diagonal case used both tools on 100 of 100 layers. The two original STEP bodies retained their placement, and both tools printed all 20 layers of the combined sliced envelope. The Release build succeeded and full CTest passed 385 of 393 with the same eight baseline failures.
- **P2-011 shared-face alignment** — Select **Align to shared face** in **Material transition** to preview a valid contact plane, then apply explicitly. The Windows desktop check restored the applied 8 mm band when Cut reopened, retained both CAD bodies and previewed two filaments through the 20-layer assembly. The regression also checked orientation under reordered parts and transformed placement. The Release app built, targeted tests passed 3 of 3, the standalone sampler passed 9 of 9, and full CTest passed 385 of 393 with the same eight baseline failures.
- **P2-012 benchmark baseline** — The [planar transition manufacturability baseline](DOCUMENTATION.md#entry-p2-20261107-13--planar-transition-manufacturability-baseline) pins the source commit, test evidence and fixtures. The experimental direct-region measurements and the current path-assignment results are tracked separately.
- **P2-013 grid-pitch benchmark** — The 1.6 mm candidate reduced short moves in every case, retained the tool-change counts and raised the generic estimate in eight of nine cases. The 4 mm diagonal outer-wall error exceeded its tolerance. The 1.2 mm pitch remains in production. See the [benchmark results](test-results/P2-013-toolpath-benchmark.md).
- **P2-014 H2D offline qualification** — The conservative companion process clears the offline acceleration warning and keeps emitted acceleration commands within the generic 1,500 mm/s² cap. See the [vendor comparison and validation](test-results/P2-014-h2d-offline-qualification.md).

Automated regression passed. Full CTest passed 387 of 395 with the same eight baseline failures. See the [qualification report](test-results/P2-015-h2d-vendor-export-audit.md).
