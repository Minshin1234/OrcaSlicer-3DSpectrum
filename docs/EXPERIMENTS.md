# Experiments

No physical specimens or material-property measurements are recorded for this project.

## Proposed E-001 — Planar rectangular specimen

Start with two adjacent cuboids and record dimensions, shared frame, signed plane, transition width, grid pitch, layer height and phase. For the digital preview, record error by window, endmember preservation, runtime and memory where measured. Once slicer integration exists, record extrusion volume by tool, switches, travel and purge estimates. Keep sharp-interface and pure-material specimens as physical controls.

Before physical execution, record exact machine, firmware, nozzles, materials, slicer revision, command review, transfer workflow and approval. Afterward record actual print conditions, inspection, failures, sample count and uncertainty. Store lightweight supporting assets under [assets](assets/README.md) and run evidence under [test-results](test-results/README.md).
